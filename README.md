# DocuLearn

A localized learning platform for Grade 10 Araling Panlipunan (AP10) students of Guimba. Combines local materials, curated documentaries, and an interactive discussion forum to help students explore contemporary issues in their own community.

## Live Site

https://ap10-forum.vercel.app

## Features

- **Authentication** — Email/password signup and login via Supabase Auth
- **Role-based access** — Students and teachers see different navigation
- **Modules** — Topic-based lessons on contemporary issues
- **Localized materials** — Images, data, and text uploaded by teachers
- **Documentaries** — Curated YouTube videos with caching and inline playback
- **Forum** — Discussions, questions, and reflections with nested replies
- **Realtime updates** — New posts appear instantly across all open browsers
- **My Progress** — Personal stats on posts, reflections, and replies
- **Admin panel** — Teachers can add topics and materials with image upload

## Tech Stack

- **Frontend:** HTML, CSS, vanilla JavaScript (ES modules)
- **Backend:** Supabase (PostgreSQL, Auth, Storage, Edge Functions, Realtime)
- **Hosting:** Vercel
- **Version control:** GitHub
